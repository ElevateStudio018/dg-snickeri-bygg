# DG Snickeri & Bygg AB – hemsida

Statisk hemsida (HTML/CSS/JS, inga beroenden) för DG Snickeri & Bygg AB i Nödinge.

- `index.html` – startsida (tjänster, om oss, utvalda projekt, process, omdömen, kontakt/offertformulär)
- `projekt.html` – projektarkiv med filter och bildgalleri (lightbox)
- `assets/data/projects.js` – projektdata (titel, kategori, ort, bilder)
- `assets/projekt/` – projektbilder hämtade från företagets Facebook-sida
- Logotyp och porträtt från dgbyggservice.se

Öppna `index.html` direkt i webbläsaren eller publicera mappen via t.ex. GitHub Pages / Netlify.
Offertformuläret öppnar ett förifyllt mejl till daniel@dgbyggservice.se.
